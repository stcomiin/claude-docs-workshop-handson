<threat_model>
## Security Threat Model

**ASVS level:** L1 local workshop runtime
**Block on:** high severity

| ID | Threat | Severity | Mitigation |
|----|--------|----------|------------|
| T-01-01 | Elasticsearch security is disabled for workshop simplicity. | Medium | Bind only `127.0.0.1:9200:9200` in Compose and document local-only use in Plan 03. |
| T-01-02 | Seed data could accidentally contain real or identifying data. | Medium | `build_seed.py` must generate synthetic user IDs/usernames/orgs only. |
| T-01-03 | Seed script could target a remote ES endpoint. | Low | `seed.py` defaults to `http://es:9200` inside Compose and accepts only `ELASTICSEARCH_URL` override. |

No high-severity threats remain after these mitigations because this is a
localhost-only instructional environment with synthetic data.
</threat_model>
