# Claude Docs Workshop Handson

Workshop guides for the curriculum published in the Claude Docs central guide.

| Workshop | Purpose |
|---|---|
| [`fastapi-template-bmad-workshop/`](fastapi-template-bmad-workshop/) | BMAD Method on an existing codebase — guides you through cloning the FastAPI template and running BMAD on it. |
| [`fastapi-template-gsd-workshop/`](fastapi-template-gsd-workshop/) | GSD on an existing codebase — same setup, GSD workflow instead. |
| [`research-report-generation-workflow-completed/`](research-report-generation-workflow-completed/) | Parallel-agent research and document generation (completed reference). |
| [`research-report-generation-workflow-starter/`](research-report-generation-workflow-starter/) | Parallel-agent research and document generation (starter). |

The two FastAPI workshops are README-only guides — you clone `fastapi/full-stack-fastapi-template` yourself and run the workflow against your clone. Both READMEs pin the template to commit `13652b51ea0acca7dfe243ac25e2bbdc066f3c4f` (2026-04-16) for reproducibility; you can use the latest `master` instead if you don't care about pinning. The two workshops share the same suggested feature so participants can compare the methods on identical inputs.

For curriculum, see the central guide `existing-codebase-workflows.md` in the `claude-docs` repo (replace with the public deploy URL once available).
